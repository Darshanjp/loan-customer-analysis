# 🏦 Loan & Customer Data Analysis

## 📌 Project Overview
A comprehensive data analysis mini project using real customer and loan datasets. Covers data extraction, cleaning, manipulation, visualization, and statistical testing.

## 🛠️ Tools & Technologies
- **Python** — Pandas, NumPy
- **Visualization** — Matplotlib, Seaborn
- **Statistics** — SciPy (T-Test / Hypothesis Testing)

## 📊 Key Analysis Performed
- Data extraction from CSV files
- Data cleaning — null values, duplicate detection and removal
- Top 5 highest and lowest loan amounts
- Cities with most loan customers
- Loan approval status distribution (Approved / Not Approved / Under Review)
- Top 5 customers with highest loan interest
- City-wise sum of loan amounts and interest rates
- Hypothesis testing (T-Test) to check statistical significance between groups

## 📁 Datasets
- `Customers_Information.csv` — Customer demographics and city data
- `Loan_Details.csv` — Loan amounts, interest rates, and approval status

## 📈 Visualizations
- Bar Charts — City-wise loan distribution
- Pie Chart — Loan approval status breakdown
- Seaborn Plots — Interest rate comparisons

## 🔍 Insights
- Identified cities with highest loan demand
- Found customers with highest financial risk (high interest rates)
- Validated statistical differences between loan groups using hypothesis testing
